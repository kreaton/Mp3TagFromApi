# Mp3ApiTag

This repository only holds the **releases** of Mp3ApiTag, a Windows app that tags one folder of mp3 files as an album, with data from Spotify or Discogs, and fixes garbled letters (mojibake).

The source code, documentation and issues are in **[kreaton/Mp3TagUpdater](https://github.com/kreaton/Mp3TagUpdater)**, in the `Mp3ApiTag.Wpf` project.

## Install

Download `Mp3ApiTag-win-Setup.exe` from the [latest release](https://github.com/kreaton/Mp3ApiTag/releases/latest) and run it. It installs the .NET 10 Desktop Runtime if it is missing. To get a newer version later, open the ⚙ settings and choose **Check for updates**.

You need your own Spotify and/or Discogs API keys; the settings window explains where to get them.
